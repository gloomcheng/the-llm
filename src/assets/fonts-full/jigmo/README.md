## Plane mapping

- `Jigmo.woff2`: BMP and the URO / Extension A Han ranges
- `Jigmo2.woff2`: SIP ranges, including Extensions B–F and I
- `Jigmo3.woff2`: TIP ranges, including Extensions G, H, and J

The site places Taiwan Traditional Chinese fonts before Jigmo in the display stack.
Jigmo is therefore a rare-character coverage fallback, not the default source for
common Taiwan glyph forms.
