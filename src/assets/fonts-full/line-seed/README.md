## Weights

- `LINESeedTW_OTF_Th.woff2`: 100 / Thin
- `LINESeedTW_OTF_Rg.woff2`: 400 / Regular
- `LINESeedTW_OTF_Bd.woff2`: 700 / Bold
- `LINESeedTW_OTF_Eb.woff2`: 800 / ExtraBold

`LINE Seed TW` is the sans-serif family for the interface and article body. The
serif display stack remains separate and continues to use the existing Jigmo rare-Han
fallback.
